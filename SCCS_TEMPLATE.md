# Standard Contractual Clauses (SCCs) — ASCENTIA s.r.o. → Tripo / Holymolly Ltd

## Prečo SCCs?

Tripo API (Holymolly Ltd) sídli v USA a nemá explicitnú DPA ani EU-US Data Privacy Framework certifikáciu. Podľa GDPR čl. 46 sú SCCs právnym základom pre mimoeurópsky prenos osobných údajov.

## Kedy to treba?

- Ak Tripo neposkytne DPA do 14 dní od žiadosti
- Ak Tripo nie je certifikovaný pod EU-US DPF
- SCCs podpisuješ ty (ASCENTIA = controller) a Tripo (processor)

## Ako na to

1. Stiahni oficiálny text: https://commission.europa.eu/publications/standard-contractual-clauses-international-transfers_en
2. Vyplň Module 2 (Controller-to-Processor)
3. Pošli Tripo na podpis
4. Archivuj podpísanú kópiu

## Čo SCCs obsahujú (Module 2)

- **Clause 1:** Purpose and scope — prenos fotiek na Tripo API na 3D generovanie
- **Clause 2:** Effect and invariability
- **Clause 3:** Third-party beneficiaries
- **Clause 4-5:** Obligations of the data exporter (ASCENTIA) and data importer (Tripo)
- **Clause 6-7:** Liability and third-party rights
- **Clause 8-9:** Data protection safeguards (confidentiality, security, sub-processing)
- **Clause 10-12:** Deletion, audits, notification obligations
- **Annex I:** List of parties, description of transfer, competent supervisory authority (Úrad na ochranu osobných údajov SR)
- **Annex II:** Technical and organizational security measures
